💡 设计总结

核心功能：

  • 📍 左按钮：返回/暂停（Back / Pause）
  • 📍 中间区域：
    • Listening 状态：声波动画 + "Listening..." 文字
    • Stopped 状态：麦克风按钮（可点击重新开始）
  • 📍 右按钮：停止（Stop / ✕）

推荐版本：
🥇 V3 / V3b（极简图标：⟨ 和 ✕）
• 最简洁清晰
• ✕ 符号表示停止很直观
• 对话空间最大

🥈 V1 / V1b（传统图标：← 和 ■）
• 标准 UI 图标
• 功能明确

技术实现（SwiftUI）：
